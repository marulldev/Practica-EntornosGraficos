1. ¿Qué es CSS y para qué se usa?

CSS son las siglas de "hojas de estilo en cascada" (Cascading Style Sheets). 
Es una tecnología que permite controlar la apariencia de una página web, describiendo cómo se presentan al usuario los elementos dispuestos en la página. 
Con CSS se pueden especificar estilos como el tamaño, las fuentes, el color, el espaciado entre textos y recuadros, así como el lugar donde disponer texto e imágenes en la página.
CSS no es un lenguaje de programación ni un lenguaje de marcado, sino un lenguaje de hojas de estilo que permite aplicar estilos de manera selectiva a elementos en documentos HTML.

2. CSS utiliza reglas para las declaraciones de estilo, ¿cómo funcionan?

Una regla CSS está compuesta por:

Un selector (por ejemplo h1), que le indica al navegador qué parte
del documento se verá afectada por esa regla.
Una propiedad (por ejemplo color), que especifica qué aspecto se va a cambiar.
Un valor (por ejemplo red), que establece el valor de esa propiedad.

Ejemplo: h1 {color: red;}

Los selectores pueden aparecer individualmente o agrupados separándolos con comas (ej: h1, h2, h3 { color: red; }).
Las propiedades que se desean modificar para un mismo selector pueden agruparse, separando cada una con punto y coma.
Normalmente se describe una propiedad por línea. Si el valor está formado por más de una palabra, debe ir entre comillas (ej: p {font-family: "sans serif";}).

3. ¿Cuáles son las tres formas de dar estilo a un documento?

Según el PDF, podemos asociar las reglas de estilo a las marcas HTML de tres maneras:
A nivel de elemento HTML: es la forma más fácil pero menos recomendada. Se define en la propiedad style del propio elemento (ej: <h1 style="color:#ff0000;background-color:#ffff00">).
A nivel de página: se definen los estilos en una sección especial de la cabecera, encerrada entre las etiquetas <style> y </style>.
En un archivo externo: es la metodología más empleada.Las reglas de estilo se guardan en un archivo separado con extensión .css, y se vincula
a la página HTML mediante la etiqueta <link rel="StyleSheet" href="estilos.css" type="text/css"> dentro del <head>.

4. Tipos de selectores más utilizados

Los selectores son patrones que determinan a qué elementos de la estructura del documento se aplica una regla, y pueden ir desde un simple nombre de elemento hasta patrones contextuales más complejosEn CSS, las reglas de las equivalencias de patrones determinan cuales reglas de estilo se aplican a los elementos en la estructura del documento. 
Estos patrones, denominados selectores, pueden ir desde el simple nombre de un elemento hasta complejos patrones contextuales. Los tipos principales que define la especificación son:

Selector universal (*): corresponde a cualquier elemento del documento, sin importar su tipo.
Selector de tipo (E): corresponde con el nombre de un tipo de elemento; por ejemplo, H1 selecciona todos los encabezados de nivel 1.
Selector de descendientes (E F): selecciona un elemento F que está contenido en cualquier nivel dentro de un elemento E, sin importar la profundidad del anidamiento.
Selector de hijos (E > F): selecciona un elemento F únicamente cuando es hijo directo de E, es decir, un nivel de anidamiento exacto.
Selector de hermanos adyacentes (E + F): selecciona un elemento F que está inmediatamente después de E, compartiendo ambos el mismo elemento padre.
Selector de atributo (E[attr]): selecciona elementos que tengan asignado un atributo determinado, sin importar su valor, o con un valor específico.
Selector de clase (.clase): en HTML es equivalente a usar el selector de atributo sobre "class"; permite aplicar el mismo estilo a varios elementos distintos.
Selector de id (#id): selecciona un único elemento identificado por ese id, que no debería repetirse en el documento.

5. Pseudo-clases

Las pseudo-clases son un mecanismo que permite aplicar estilos según características de un elemento que no se deducen directamente de su nombre, atributos o contenido en el documento fuente; algunas de ellas son dinámicas, ya que un elemento puede adquirirlas o perderlas mientras el usuario interactúa con la página.

Las pseudo-clases más utilizadas aplicadas a vínculos son:

:link → se aplica a los enlaces que todavía no fueron visitados.
:visited → se aplica una vez que el enlace ya fue visitado.
:hover → se aplica mientras el usuario señala el elemento con el mouse, sin activarlo.
:active → se aplica durante el momento en que el usuario está activando el enlace (por ejemplo, mientras mantiene presionado el botón del mouse).

La especificación aclara además que :hover debe declararse después de :link y :visited para que la cascada no oculte su efecto, y que :active debe ir después de :hover.

6. Herencia

La herencia es el mecanismo por el cual ciertos valores de propiedades se transmiten de un elemento a sus elementos descendientes en la estructura del documento, y cada propiedad CSS define individualmente si se hereda o no. Por ejemplo, si no se asigna un color específico a un elemento anidado, este tomará el color heredado de su elemento padre. 
También existe el valor especial inherit, que se puede usar para forzar explícitamente que una propiedad tome el valor computado de su elemento padre, incluso en propiedades que normalmente no se heredan.

7. El proceso de cascada

La cascada es el mecanismo que determina qué valor final aplicar a una propiedad cuando existen varias reglas en conflicto para el mismo elemento. Las hojas de estilo pueden provenir de tres orígenes distintos: el autor de la página, el usuario (o su navegador) y la aplicación de usuario (el navegador con su hoja de estilo predeterminada).
 Para resolver los conflictos, el navegador sigue este orden:

Origen e importancia: por defecto, las reglas del autor tienen más peso que las del usuario, salvo que se use la marca !important, en cuyo caso el orden se invierte.
Especificidad del selector: se calcula contando la cantidad de ids, clases/atributos/pseudo-clases y nombres de elemento en el selector; a mayor especificidad, mayor prioridad.
Orden de aparición: si dos reglas tienen exactamente la misma fuerza, origen y especificidad, gana la que fue escrita en último lugar.

Este conjunto de reglas para resolver conflictos entre estilos es lo que da nombre a la tecnología: hojas de estilo en cascada.
